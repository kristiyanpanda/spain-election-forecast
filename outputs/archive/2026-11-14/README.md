# Outputs of the 14 November 2026 run

A copy of `outputs/` as written by the interim run with data to 14 November 2026 (commit `ee4ec82`),
kept for comparison with the final run of 23 November. `polls_wide.csv` and `cis_studies.csv` are the
processed poll and CIS files that run used. The posterior trace and the backtest cache are not included.

Headline of that run, for 29 November: PP 128 seats (105-151), PSOE 109 (89-131), Vox 67 (52-85);
PP + Vox majority 94 %, PP largest party 78 %. Same model code as the final run; the final run adds
the polls of 14-22 November and our re-estimate of the CIS pre-election microdata (see
`docs/methods_note.md` §14).
